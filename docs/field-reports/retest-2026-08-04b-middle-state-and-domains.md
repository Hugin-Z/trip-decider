# 第四次复测要点

第三次实测（2026-08-04）是**重大进展**：宿主主动调用、秒级响应、12306 实查数据
（含余票与采集时刻）进入最终行程，宿主还自发按证据词表给行程分级
（「车次实查可信 / 门票网页待核验」）——那正是这套东西想要的效果。

同一次实测撞出两个新缺陷，本轮都修了。第四次复测主要看这两处是否消失，以及
当地交通粒度是否达标。

---

## 本轮修了什么（复测时对照）

| # | 第三次实测的症状 | 归因 | 现在 |
|---|---|---|---|
| a | create/confirm 后 advance 报 `action loop was not started`，宿主盲试多次 | **异步化引入的中间态**：候选比较阶段 run 已是 RUNNING，但动作循环要等选定候选之后才建；`advance` 一头扎进去撞上内核异常 | 该状态不再对外存在。比较阶段返回 `checkpoint="COMPARING_CANDIDATES"` 加 `progress`（已比完 n / 共 m） |
| a' | 那条错误没有 `next_call` | 上一轮的守卫是**按当时的错误清单**逐条核对的，新增错误类型自动漏网 | `next_call` 改成构造函数**必填**（省略是 TypeError），外加 AST 扫描所有构造点与 `_guard` 调用点 |
| b | 提交班车证据被反复拒绝，最终手排时间轴 | map 域**根本没有提交门**：形状不合的提交被静默接受，编译器产出 0 事件 + `MAP_INPUT_UNAVAILABLE`，需求仍缺、动作重派 | 补 `_validate_map_value`，门口就拦并点名缺什么、附最近的合法形状；线路措辞的写法也接 |

**b 的归因结论**（任务问的是「校验过严还是 schema 不支持」）：**是 schema 不
支持那个形状，而且没有任何地方说得清**。宿主提交的是「线路」（`line` /
`board_at` / `alight_at` / `fare`），schema 要的是「段」（`from` / `to` /
`duration_seconds`）。两件事都做了：schema 现在**接受**线路信息作为可选补充
（此前它无处安放），同时**明确拒绝**缺了段要素的提交并说明。

## 场景 A：中间态是否消失

> 我想 8 月中旬从武汉出发去婺源上饶那边玩三四天，两个人，预算 6000，
> 节奏慢一点，想看自然和古村。帮我安排一下。

（说得含糊些，确保走 GUIDED_DISCOVERY——那正是撞出中间态的路径。）

| # | 看什么 | 通过 |
|---|---|---|
| A1 | 有没有出现 `action loop was not started` | **没有**。这是硬指标 |
| A2 | 比较阶段的 `advance` 返回什么 | `COMPARING_CANDIDATES`，带 `progress.compared_count` |
| A3 | 宿主是否安心等待 | 它应当照着 `next_call` 再调一次，而不是改调别的工具 |
| A4 | 任何一条错误 | 都应带「下一步：…」 |

## 场景 B：班车证据能不能提交进去

拿到行程后，故意让它补一段当地交通：

> 景区里有班车，我查到是「甲村游客中心」上车、「丙村索道下站」下车，
> 15 块钱，6 点半首班、每 25 分钟一班。帮我加进行程。

| # | 看什么 | 通过 |
|---|---|---|
| B1 | 它是否调 `submit_trip_evidence(action_id="map")` | 是 |
| B2 | 第一次若被拒 | 报错要**点名缺 `duration_seconds`**（宿主没说这段要坐多久），并给出照着改就能过的形状 |
| B3 | 宿主是否补上时长后一次成功 | 应当。**不应**再出现反复试错 |
| B4 | 班车是否进了时间轴 | 事件上应有线路名、上下车站、15 元、每 25 分钟一班 |
| B5 | 报错里的示例是不是 map 域的 | 此前不论提交什么域都贴 railway 示例；现在应贴 map 的 |

**注意 B2 是设计而非缺陷**：「这段要坐多久」是排时间轴的必需信息，编不出来也
不该编。要看的是**拒绝得清不清楚**，不是拒不拒绝。

## 场景 C：当地交通粒度（第三次点名）

> 第二天从住的地方到景点这一段，具体怎么走？

**验收样例**（宿主上次自己 web search 补的粒度）：「1路2路公交2元」
「老北站班车6:30起每25分钟」。

| 要素 | 工具现在给不给 | 说明 |
|---|---|---|
| 乘什么（线路名） | ✅ | |
| 在哪上/下车 | ✅ | |
| 坐几站、坐多久 | ✅ 本轮新增 | |
| 每段步行多远、多久 | ✅ 本轮新增 | 「先走 840 米 → 坐 9 站 → 再走 100 米」 |
| 票价 | ✅ | 高德给才有，不给就标待核验 |
| 首班车 / 发车间隔 | ❌ 高德给不出 | 实测 `start_time`/`end_time`/`bus_time_tips` **都返回空字符串**。但**手工提交现在接**这三个字段 |

本轮增量是**纯解析**：实测确认给 `show_fields` 加 `steps` 与不加，响应结构
**逐字节一致**（transit 端点不认这个值），所需数据本来就在响应里。零请求变更、
零额外网络往返。

真实落地样例（2026-08-04 实查）：

```
步行 840 米（约 12 分钟）
→ 地铁2号线：人民广场 上，虹桥火车站 下（9 站、约 32 分钟）
→ 步行 100 米（约 1 分钟）
票价 5.0 元 · 全程步行 940 米
```
