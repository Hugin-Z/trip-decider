# README 截图占位清单

公开首页暂不引用现有 field-report 截图。补图时使用公开演示数据，在同一次干净运行中
完成以下画面；建议统一为 1440×900 PNG，并在 1× 显示比例下确认文字可读。

| 文件名 | 必须展示 | 验收重点 |
| --- | --- | --- |
| `01-intent-confirmation.png` | Discover 模式、出发地/日期/预算/偏好与待确认意图 | 输入使用公开演示值；不出现浏览器账户、通知或任务栏 |
| `02-guided-candidates.png` | 已验证候选、往返交通、净可玩时长和落选原因 | 同时露出“查询失败”和“现实不可达”的区分 |
| `03-plan-timeline.png` | 从去程到返程的逐日时间轴、缓冲和住宿片区 | 不把 unknown 渲染成确定值 |
| `04-evidence-next-action.png` | 至少两个不同证据 token 及对应 `next_action` | 可靠性、新鲜度与待办都清晰可读 |
| `05-map-transit.png` | 地图、路线线条、公交上下车信息或驾车兜底说明 | 画面不得包含 key、坐标查询串或调试面板 |
| `06-revision-history.png` | 一次约束修改前后的版本与当前生效版本 | 能看出失败的新版本不会覆盖已有可用版本 |
| `07-mcp-host.png`（可选） | MCP 宿主中调用 trip-decider 的最小对话 | 裁掉账号头像、侧栏、会话标题和宿主个人信息 |

## 拍摄前检查

- 使用仓库公开示例或专门构造的演示日期、人数和预算，不使用 Hugin 的真实行程；
- 新建浏览器访客配置或裁掉浏览器 chrome，不显示账号、书签、扩展和下载记录；
- 隐藏终端、环境变量、绝对路径、`run_id`、runtime 文件名和调试响应；
- 在开发者工具 Network、URL、页面 DOM 和截图像素中检查 key、安全密钥与请求签名；
- 地图若显示精确起居位置，改用公共交通枢纽或公开景点；
- 导出后逐张 OCR/放大复核，再用扫密规则检查旁车文件与元数据。

## 现有截图处置

`docs/field-reports/*.png` 保留为历史实测证据，但含具体日期、车次、预算和故障
上下文。它们不适合作为公开首页素材，也不应复制到本目录。公开截图应按上表重新拍摄。
