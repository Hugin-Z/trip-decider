## 3. WU1/WU1C 消费关系

WU2 consumes, but does not extend, these public contracts:

| Existing contract | WU2 use |
|---|---|
| `load_document` | strict UTF-8/JSON loading of produced artifacts |
| `canonical_payload_sha256` | integrity hash after the payload is independently formed |
| `validate_artifact` | candidate/evidence envelope and Schema validation |
| `validate_bundle` | `jiangxi_smoke` closed bundle with explicit evidence root |
| `validate_fixture_manifest` | WU1C `open_data_anchor` persistence metadata |
| `ValidationProblem` / `ValidationResult` | deterministic adapter input failures without a second error model |
| candidate provider contract | `name`, native ID/type/categories/status and orthogonal policy |
| provider location contract | explicit WGS84 and coordinate-local source refs |
| evidence contract | relation subject, value/unit, support, derivation, freshness, source, normalization and display fields |

The smoke fixture contains three validated documents:

```text
request artifact
    ↑ request_ref
candidate artifact
    ↑ relation entity refs
evidence artifact (explicit CLOSED root)
```

The request is a synthetic deterministic structural input, not a travel
recommendation. The candidates and evidence are normalized from real source
anchors. Closed validation proves artifact shape, hashes, the request
reference and candidate entity references; it does not prove geographic
truth, route quality, freshness, feasibility, ranking, or planning.

Existing contract decisions remain unchanged:

- provider-backed coordinates require an explicit supported CRS;
- unknown CRS becomes a hard adapter error, not guessed coordinates;
- route time is an API estimate, never direct observation or verified fact;
- replay permission is explicit and not inferred from persistence;
- no LLM is a fact source;
- no city name is visible to planner, constraint, evidence, or domain logic.

## 4. 数据源选择

All observations below were checked on 2026-07-28 from project, provider, or
foundation pages. C1 rechecks them before any capture and records actual
access results in `docs/wu2-source-decision.md`. This is engineering policy,
not legal advice.

### 4.1 Selected POI anchor: OpenStreetMap through one Overpass snapshot

Decision: **selected for the WU2 non-production real anchor**.

Basis:

- OSM data is ODbL 1.0 data and permits copying/adaptation subject to
  attribution and share-alike obligations:
  <https://www.openstreetmap.org/copyright>.
- OSMF attribution guidance requires OpenStreetMap attribution and makes the
  ODbL basis visible:
  <https://osmfoundation.org/wiki/Licence/Attribution_Guidelines>.
- OSM raw coordinates use WGS84:
  <https://wiki.openstreetmap.org/wiki/Elements>.
- Overpass is a read-only OSM data path intended for selected extracts; the
  public-instance page identifies `https://overpass-api.de/api/interpreter`
  as a third-party global instance and publishes capacity guidance:
  <https://wiki.openstreetmap.org/wiki/Overpass_API>.
- `out center` supplies coordinates for ways/relations but its center is not
  guaranteed to lie inside the feature:
  <https://wiki.openstreetmap.org/wiki/Overpass_API/Overpass_QL>.

Execution constraints:

- one bounded query for the named Wuyuan smoke targets;
- `out center tags`, never `out meta`, to avoid contributor-account metadata;
- one identified client, a bounded timeout, and no retries beyond the
  pre-registered single retry for transport failure;
- exact response bytes, query, endpoint, retrieval time, response hash, OSM
  base timestamp, license and attribution are recorded;
- object identity is `(type, id)`, never `id` alone;
- a way/relation center is represented as the provider's reported center and
  is not claimed to be an entrance or field observation.

If the query cannot unambiguously identify approximately five supplied
targets, the anchor is `BLOCKED`; no fuzzy name guess, Nominatim fallback, or
invented coordinate is allowed.

### 4.2 Conditional route anchor: OSRM demo response over OSM data

Decision: **conditional, non-production, anchor-acquisition only**.

Basis:

- OSRM documents route requests as
  `{longitude},{latitude};{longitude},{latitude}` and returns route duration:
  <https://github.com/Project-OSRM/osrm-backend/blob/master/docs/http.md>.
- OSRM software is BSD-2-Clause, but that software license is not used as the
  data/replay license:
  <https://github.com/Project-OSRM/osrm-backend/blob/master/LICENSE.TXT>.
- The project demo-server page limits the shared service to reasonable,
  non-commercial use, at no more than one request/second, with no uptime,
  latency, or data-update guarantee:
  <https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server>.
- OSMF routing attribution guidance treats OSM-derived routing output
  separately from the underlying OSM database and still requires OSM credit:
  <https://osmfoundation.org/wiki/Licence/Attribution_Guidelines>.

The approved execution may make exactly two serialized route requests solely
to prepare this open-data smoke anchor. It must request one driving route
with no alternatives, geometry, steps, annotations, or hints. The committed
anchor retains the exact response and attributes the underlying OSM data
under ODbL; it does not claim that BSD licenses the route data.

This path hard-stops if the C1 recheck cannot support persistent fixture
retention, the endpoint policy changed, the response is not attributable to
OSM data, China coverage returns no unambiguous route, the response contains
fields that cannot be safely committed, or a credential is required. WU2
does not self-host OSRM because that would introduce an unapproved runtime,
data build, and dependencies.

Tests never call OSRM. The product has no live OSRM client and no production
provider selection.

### 4.3 Rejected WU2 source: public Nominatim

Decision: **not used for POI harvesting, target disambiguation, tests, or
production**.

The official public-service policy sets an absolute maximum of one
request/second, discourages bulk geocoding, forbids systematic downloading of
all POIs in an area, has no general SLA, and requires switchability:
<https://operations.osmfoundation.org/policies/nominatim/>.

The named smoke targets do not justify turning a public geocoder into a data
pipeline. Failure to identify a target through the bounded OSM snapshot is a
blocker, not permission to query Nominatim.

## 5. Adapter 设计

WU2 implements exactly two city-independent normalizers. “Adapter” in WU2
means a strict external-record-to-artifact boundary, not a live production
client.

### 5.1 Shared input boundary

Both adapters accept an explicit mapping plus an explicit normalization
context. The minimum wire fields frozen by tests are:

```yaml
format_version: "0.1.0"
provider:
operation:
crs:
retrieved_at:
request_fingerprint:
response_locator:
data_policy:
result:
  status: success | error
  document:
  provider_error_code:
```

`document` is present only on success; `provider_error_code` is present only
on error. Unknown or extra top-level/result fields fail. Provider, operation,
CRS, policy and retrieval time are never filled from defaults. Input values
are not coerced.

The public surface is deliberately small:

```python
normalize_open_data_pois(snapshot, context) -> ValidationResult[dict]
normalize_route_evidence(snapshot, context) -> ValidationResult[dict]
run_jiangxi_smoke(replay_root, output_root) -> ValidationResult[RunSummary]
```

No fetch method is exported. Internal dataclasses and helpers are not frozen
as downstream API.

### 5.2 Open Data POI Adapter

Accepted source document: one Overpass JSON response containing only
`node`, `way`, or `relation` elements.

Deterministic rules:

- require `provider == "osm"`, `operation == "overpass-poi-snapshot"`,
  `crs == "WGS84"`, and an exact WU1C `open_data_anchor` policy;
- require a non-empty element list;
- require unique `(type, id)` pairs;
- require `tags.name` exactly; no `name:zh`/English/fuzzy fallback;
- node coordinates come from `lat`/`lon`; way/relation coordinates come
  from explicit `center.lat`/`center.lon`;
- require at least one provider-native category from a fixed, documented
  tag-key allowlist; emit every present category in lexical key order as
  `code: key=value`, with the raw value preserved;
- emit `external_status.kind: not_reported`;
- emit `candidate_kind: poi` without ranking or destination semantics;
- emit record and coordinate-local `provider_item` locators containing the
  explicit OSM type and ID;
- set `generation_stage: poi_discovery` only because that is the existing
  structural enum; `generation_reason` states import/no ranking;
- order candidates by `(type, numeric id)`, not source response order;
- create stable run-scoped IDs using the documented SHA256-to-UUID-shaped
  algorithm with explicit namespace and version/variant bits; the algorithm
  is tested against fixed handwritten vectors.

Missing label, category, coordinate, CRS, provider, policy, or an empty/error
response returns a deterministic `ValidationProblem`. A bad item never
disappears silently and never produces a partial success.

### 5.3 Route Evidence Adapter

Accepted source document: two named OSRM `route/v1/driving` responses, each
requested with `alternatives=false`, `overview=false`, `steps=false`,
`annotations=false`, `generate_hints=false`, and `skip_waypoints=true`.

Deterministic rules:

- require `provider == "osrm"`, operation `route/v1/driving`, input CRS
  `WGS84`, and exact origin/destination candidate IDs supplied by replay
  metadata;
- require provider response `code == "Ok"` and exactly one route;
- require a finite, non-negative numeric `duration`;
- do not choose a “best” route, infer a mode, or convert coordinates;
- emit relation subject `route`, mode `driving`, field `travel_time`;
- preserve the numeric duration as `value` and `normalization.original_value`;
- use unit `second`;
- use `support_status: sourced`, `derivation: api_estimate`, and
  `display_status: estimated`;
- set freshness times from the captured retrieval time but use
  `freshness.status: unknown`, with null effective/expiry times;
- record an `api_response` source with provider, operation, retrieval time,
  request fingerprint and fixture-local response locator;
- use an explicit structural display rule. WU2 does not implement a general
  evidence-state mapper, trust score, conflict resolver, or freshness score.

An empty route list, multiple routes, non-`Ok` code, missing duration,
missing CRS/provider, or invalid type hard-fails. No first-route fallback is
reachable.

### 5.4 Stable adapter problem codes

Tests freeze these WU2 codes:

```text
INGESTION_INPUT_INVALID
INGESTION_PROVIDER_MISSING
INGESTION_CRS_MISSING
INGESTION_CRS_UNSUPPORTED
INGESTION_POLICY_INVALID
INGESTION_RESPONSE_EMPTY
INGESTION_PROVIDER_ERROR
INGESTION_RECORD_INVALID
INGESTION_ROUTE_COUNT_INVALID
INGESTION_DURATION_INVALID
```

Each problem uses the existing seven-field `ValidationProblem`, safe
`actual_type`, stable JSON Pointer and fixed message. It never copies a
provider exception, response value, URL query secret, or raw body.

## 6. Raw / Replay 策略

### 6.1 Temporary raw capture

Commercial-live capture is not implemented. The bounded acquisition process
for an eligible source uses:

```text
network response
  -> random file under the system temporary directory
  -> hash and policy preflight
  -> either approved open-data replay anchor
     or normalization followed by deletion
  -> finally verifies temporary deletion
```

No raw response enters `runtime/`, `data/raw/`, logs, stdout, or Git before
the source-policy gate succeeds. Deletion failure is a hard failure.

### 6.2 Persistent replay anchor

The committed `jiangxi_smoke` anchor is allowed only when all WU1C fields are
explicit:

```yaml
source_class: open_data
capture_mode: persistent_anchor
storage_policy: persistent_allowed
replay_allowed: true
fixture_allowed: true
license:
  identifier: ODbL-1.0
  url: https://opendatacommons.org/licenses/odbl/1-0/
  attribution: © OpenStreetMap contributors
```

The replay manifest records:

- exact source endpoint and request descriptor;
- retrieval time and response/source base time when available;
- response SHA256;
- explicit WGS84;
- object/route selection IDs;
- exact input and expected-output relative paths and SHA256 values;
- adapter and mapping versions;
- network required: false;
- coverage and non-coverage.

Offline replay rejects path traversal, hash drift, unknown/extra files,
policy drift and any attempt to open a network socket. Run outputs go to
ignored `runtime/wu2/jiangxi_smoke/<run-id>/`; no raw capture is copied there.

## 7. Candidate / Evidence 映射

| Artifact field | External input | Rule |
|---|---|---|

| `candidate_kind` | WU2 adapter contract | literal `poi`, not inferred from tourism value |
| `label` | `tags.name` | exact string, no fallback |
| `parent_candidate_id` | none | null; WU2 does not build hierarchy |
| `provider.name` | snapshot provider | exact `osm` |
| `provider.record_id` | OSM ID | decimal string |
| `provider.record_type` | OSM type | node/way/relation |
| `provider.categories` | allowed raw tags | lexical `key=value`, no taxonomy mapping |
| `provider.external_status` | absence in source contract | explicit `not_reported` |
| `provider.data_policy` | replay metadata | exact open-data policy |
| `location.latitude/longitude` | node or explicit center | unchanged numeric WGS84 |

The candidate artifact also has a fixed smoke request reference,
`generation_stage: poi_discovery`, an empty `rejected_inputs`, explicit

### 7.2 Evidence field map

| Artifact field | Route input | Rule |
|---|---|---|
| `fact_id` | pair identity plus fixed namespace | deterministic SHA256 ID rule |
| `subject` | replay pair | relation/route/from/to/driving |
| `field` | adapter contract | `travel_time` |
| `value`, normalization values | OSRM `routes[0].duration` | unchanged finite number |
| `unit` | OSRM HTTP contract | `second` |
| `support_status` | sourced API response | `sourced` |
| `derivation` | route algorithm output | `api_estimate` |
| `freshness` | capture metadata | retrieved time; status unknown |
| `sources` | request/response metadata | API source, no LLM |
| `display_status` | frozen v3.1 boundary | `estimated`, never verified |
| `conflict_source_refs` | WU2 non-conflict input | empty, no conflict judgment |
| `derivation_detail.estimate` | duration | OSRM method/value/second |

`mapping_rule_version` freezes only this structural adapter mapping. It is
not the WU3 evidence support/freshness/conflict engine.

The supplied names are selection seeds, not expected facts. Actual

`case.json` is a WU1C `real_anchor` / `open_data_anchor` manifest with:

- explicit `CLOSED` evidence root;
- an independently authored synthetic smoke request;
- expected candidate and evidence documents embedded as UTF-8 bytes;
- exact document hashes and expected Schema IDs;
- source license/attribution;
- concrete coverage and non-coverage;
- zero dirty cases, because adapter mutations live in focused unit tests.

`replay.json` points to the two raw files and to the embedded expected
artifacts using fixed hashes. Expected labels, IDs, coordinates, route
seconds, JSON Pointers and artifact payloads are transcribed/calculated from
the source bytes and written before the pipeline green. The adapter is never
called to generate expected output. Existing, independently tested
`canonical_payload_sha256` may calculate only the envelope integrity field.

The real anchor does not cover:

- completeness or correctness of OSM in China;
- whether a center is an entrance;
- current road closures or traffic;
- route quality or real journey time;
- attraction opening hours;
- recommendation, feasibility, planning or ranking;
- a production-provider decision.

## 12. Blocking

Stop the entire WU2 before the next commit if:

- any baseline, Plan, handbook or frozen-input hash gate fails;
- a required primary page is inaccessible or no longer supports the planned
  source/storage/replay classification;
- target identity cannot be disambiguated from captured source bytes;
- OSRM China coverage does not return the two explicit unambiguous routes;
- persisting an OSRM response cannot be supported under the recorded
  open-data/policy basis;
- capture would retain contributor personal metadata, a credential, secret,
  commercial response, or unapproved field;
- a test requires live network access;
- a source failure would force Nominatim, commercial, synthetic-as-real,
  memory-based or LLM fallback;
- any adapter needs a guessed/default CRS, provider, category, route, label,
  timestamp, status or permission;
- the implementation needs a new dependency, runtime, Schema, validator,
  fixture policy, artifact type, fourth source module, or seventeenth path;
- a formal real anchor must be generated by the adapter under test;
- C4 requires a test change, C6 requires a fixture/test change, or any
  non-red commit ends with a failing test;
- a raw temporary file cannot be deterministically deleted;
- source/fixture terms would require publication behavior not represented by
  the approved policy;
- any product behavior from WU3/WU4/WU5, WU2 production integration, Web
  scraping, recommendation, destination discovery, feasibility, route
  optimization, ranking, HTML, or real trip planning becomes necessary.

On a blocker, preserve only already approved commits, record the exact
command/access result and stop as `BLOCKED` or `INCOMPLETE`. Do not switch
provider, change the Plan, expand scope, push, create a remote, start WU3, or
prepare another work-unit Plan without Hugin direction.
